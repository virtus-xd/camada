# Security

## Supported versions

Security fixes target the latest release and the `main` branch.

## Reporting a vulnerability

**Do not open public issues for vulnerabilities.** Use GitHub's private reporting form:

**[Report a vulnerability](https://github.com/virtus-xd/camada/security/advisories/new)**

Describe what the vulnerability is, how to reproduce it and what its impact is. We aim to respond within 7 days; details are kept private until a fix is released.

## In scope, for example

- Situations where the taskbar cannot be restored and the user is left without a taskbar.
- Leaks of the Gemini API key, Ada's memory or the Spotify token (these are stored on the PC encrypted with Windows DPAPI).
- Microphone audio being sent while Ada is off or without the user's consent.
- Camada granting another app or user unauthorized access.

## Türkçe

Güvenlik düzeltmeleri en son yayımlanan sürüme ve `main` dalına yapılır. Güvenlik açıklarını **herkese açık issue olarak açmayın**; GitHub'ın özel bildirim formunu kullanın: **[Güvenlik açığı bildir](https://github.com/virtus-xd/camada/security/advisories/new)**. Bildirimde açığın ne olduğunu, nasıl yeniden üretileceğini ve etkisini yazın. İlk yanıtı 7 gün içinde vermeyi hedefliyoruz; düzeltme yayımlanana kadar ayrıntılar gizli tutulur. Kapsam örnekleri: görev çubuğunun geri getirilemediği durumlar; Gemini anahtarının, Ada hafızasının ya da Spotify belirtecinin (Windows DPAPI ile şifreli) sızması; mikrofon sesinin Ada kapalıyken ya da izinsiz gönderilmesi; Camada'nın başka bir uygulamaya ya da kullanıcıya yetkisiz erişim vermesi.
